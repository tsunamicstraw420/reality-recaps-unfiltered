Privacy Policy

Reality Recaps Unfiltered · Last updated 2 October 2026

This policy covers the Reality Recaps Unfiltered website and RRU Uploader, a private application used by the owner of the Reality Recaps Unfiltered YouTube channel to publish that channel's own videos.

In short: RRU Uploader is a personal publishing tool. It is operated by the channel owner, on the channel owner's own account, and it is not offered to the public. It collects no information from visitors or from any other person.

Who this applies to

RRU Uploader has exactly one user: the owner of the Reality Recaps Unfiltered channel. It is not a product, a service, or a sign-up. No one else can authorise it or use it.

What data the application accesses

When the channel owner signs in with Google, the application is granted access to that Google account's YouTube data in order to:

  • upload video files to the channel
  • set each video's title, description, tags, visibility and scheduled publish time
  • set a video thumbnail
  • attach a subtitle (caption) track

These actions are performed only on the channel owner's own YouTube channel, and only when the channel owner runs the application.

What is stored, and where

  • An OAuth token issued by Google is stored locally on the channel owner's own computer so the application does not have to ask for sign-in every time.
  • A local file records which videos have already been uploaded, so a repeated run cannot post the same video twice.

Nothing is transmitted to, or stored on, any server operated by Reality Recaps Unfiltered. There is no database, no account system, and no hosting of user data.

What is never done

  • No data is sold, rented, or shared with third parties.
  • No data is used for advertising or ad targeting.
  • No data is used to train artificial-intelligence or machine-learning models.
  • No data is read from, or written to, any Google account other than the channel owner's.

Google API Services — Limited Use

RRU Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from the Google account's third-party access page, which immediately invalidates the stored token.

Website visitors

This site is static. It sets no cookies, runs no analytics, and collects nothing from visitors. It is hosted on GitHub Pages, whose own infrastructure logs are described in GitHub's Privacy Statement.

Children

This site and the application are not directed to children under 13 and collect no information from them.

Changes

If this policy changes, the revised version will be posted on this page with a new date.
